# Security Policy

## Supported versions

Security fixes are currently provided for the latest version on the `main` branch.

## Reporting a vulnerability

Please do not publish exploitable vulnerability details in a public issue.

Use GitHub's private vulnerability reporting feature for this repository, when available. Include the affected version/commit, reproduction steps, impact, and any suggested mitigation. Do not include real credentials, API tokens, or private user data.

MaintainerLens is a prototype and should not be exposed to untrusted users without appropriate application authentication and network controls.
